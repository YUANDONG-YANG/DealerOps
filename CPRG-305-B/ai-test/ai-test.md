As mentioned in class, students may earn bonus marks through active class participation or optional extra work.

You can earn these bonus marks by contributing effectively to in-class exercises and/or providing correct, well-explained answers to questions raised by the instructor.

Alternatively, you may complete one of the following tasks:

State Transition and Decision Tables: Develop a complete state transition table and a decision table for relevant features of your Capstone Project.

AI-Generated Test Cases: Provide an AI tool with requirements for a login or registration feature and ask it to generate test cases. Evaluate the results for correctness, coverage, and duplication. Submit an improved set of test cases with explanations of your changes.

Boundary Value Testing with AI: Provide an AI tool with clearly defined rules for age, password length, or purchase limits. Ask it to identify equivalence partitions and boundary values. Verify its output, correct any mistakes, and develop corresponding test cases.

Testing an AI Chatbot: Design and execute tests to evaluate a chatbot’s accuracy, consistency, handling of unclear questions, and compliance with instructions. Document your expected results, actual results, and findings.

AI-Generated Automated Tests: Ask an AI tool to create unit tests for a small function. Run the tests, verify the assertions, and add any missing test scenarios. Submit the final tests, execution results, and an explanation of your corrections.

For all AI-related tasks, include your prompts, the original AI responses, and a brief reflection explaining how you verified and improved the output.

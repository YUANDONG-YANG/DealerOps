01Test / QA

Proof the delivery works, and where the test code and results live.

Playwright specs — 14 API specs and 22 UI specs under playwright/tests/api and playwright/tests/ui — cover each requirement ID's acceptance cases, run against the private e2e stack started by playwright/scripts/e2e-stack.sh (see playwright/README.md). Five GitHub Actions workflows under .github/workflows/ build and validate dealer-core, dealer-gateway, ai-service, and dealer-web on pull requests and on pushes to main that touch each project's own paths; a fifth workflow runs Terraform format and schema validation only on changes under deploy/terraform/ — it holds no Azure credential and never runs plan or apply. 03Product

What was built against the original scope, and what was cut, deferred, or simulated.

A multi-tenant dealership operations platform for Ontario used-car dealers: inventory (DMS), customers and leads (CRM), reconditioning, a payment ledger, a public buyer site, and OMVIC advertising compliance checked by fixed rules plus a real AI review. Four services ship: the React web app, the gateway, the core business service, and a stateless AI service, all on Microsoft Azure via Terraform.

100%

Audited writes (by design)

Every sign-in and every create/update/delete writes its audit row in the same database transaction as the business write, so one cannot succeed without the other. A code-level guarantee, not a measured sample — see design/20-Observability.md and the system design page's §10.

Full feature list, business logic, and architecture per feature are in the system design page (§§1, 7, 17).

Known limitations

The authoritative table is in the system design page's §16 Scope and limitations and in design/SCOPE-BASELINE.md. In short:

  • Simulated: marketplace publishing (Kijiji, AutoTrader.ca) — needs a partner agreement and dealer API credentials not available to this project.
  • Not built: card payment processing (needs a merchant account and PCI scope), document OCR, a message queue, a second database.
  • Partial: production deployment is operator-run, not fully automated, because CI holds no Azure credential.
  • Template, not legal advice: the bill of sale is a printable template, not a lawyer-reviewed contract.
  • Opt-in, not switched on: custom domain binding is supported by Terraform but not yet turned on for the live demo.

06Operations

How to deploy it, and what access an operator needs.

Azure deployment

Deployment is Terraform-driven and is run by an operator holding the Azure credential; CI builds and validates but does not hold that credential. From the repository root, after az login and selecting the subscription, a normal deploy keeps whatever data is already in Azure:

./deploy/deploy.sh --apply

--seed replaces Azure's data, not just loads it. Adding --seed to the command above (./deploy/deploy.sh --apply --seed) exports the local development database and replaces the rows already in Azure after a backup. Use it only to load a first database or to deliberately reset the demo — never on a dealership's live data without confirming first.

Full prerequisites, the pushed-commit requirement, and the pre-terraform destroy backup step are in deploy/README.md. Local start order for the four services is owned by §2 Development.

Access and handover

No credentials, API keys, or connection strings are published in this repository or on this page, in line with the project's configuration-protection rule. What an incoming operator needs:

  • Source control: github.com/YUANDONG-YANG/DealerOps — request collaborator access from Yuandong Yang (Robin).
  • Azure subscription access: required to run ./deploy/deploy.sh; held by the operator who last deployed. Request access through Robin.
  • Local configuration: dealer-platform/env.example lists every environment variable a new environment needs, with no real values filled in.
  • Jira: project KAN on sait-group2-private; roster in design/TEAM.md.

Rate-limit values and SLO targets ship with configurable defaults and await the dealership's confirmation before production use.

Project summary

DealerOps is a multi-tenant web platform for independent vehicle dealerships. It brings inventory, customers, leads, work orders, payments and reporting into one application, with a read-only AI assistant. Before an advertisement is exported, fixed Ontario (OMVIC) based rules check the required details, and eligible ads then receive an AI wording review; an ad is never marked as passed when the reviewer is unavailable. Built with React 19, .NET 10 and MySQL 8 and deployed to Azure with Terraform, the platform isolates dealership data on the server. Marketplace publishing is simulated, and card payments are not processed.

The problem

  • Stock, customers, sales, ads and repairs are coordinated across disconnected tools.
  • Ads must state the all-in price, financing terms and dealer identity; omissions are easy to miss.
  • Shared access is risky: one store could see another store's data or edit a sold vehicle.
  • A check goes stale after a vehicle changes, and AI must never overrule a failed rule.

The solution

  • One application for inventory with VIN decode, customers, leads, work orders and reporting.
  • Two-stage ad check: fixed OMVIC-based rules first, then an AI wording review.
  • Server-enforced dealership isolation, role checks and an append-only audit trail.
  • Approved ads reach a public buyer site, where an inquiry becomes a sales lead.

Only the gateway is reachable from the browser. The core owns authentication, dealership isolation and persistence, and AI provider keys stay on the server.

  • Every query is scoped to the signed-in dealership.
  • Role and membership checks run in the core.
  • Passwords use BCrypt; JWT carries the identity.
  • Writes and sign-in attempts are audited.

How advertisement compliance works

1
Write the ad Staff draft a listing from the vehicle record.
2
Run fixed rules Price, financing, condition and dealer details are checked.
3
AI review Eligible ads get an AI wording review of the copy.
4
Export Only a current passed check allows export.
Safeguard: the AI review never overrides a failed fixed rule, and an ad is never marked as passed when the reviewer is unavailable. Editing the vehicle makes the check stale and blocks export until it is run again.

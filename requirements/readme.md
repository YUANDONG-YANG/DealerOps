# Requirements Documentation

All `.doc`, `.docx`, and `.pdf` files in this directory are customer-provided requirements documents. Use them as the basis for requirements analysis and implementation of the DealerOps project.

The [`analysis/`](analysis/) directory contains the requirements breakdown and analysis based on those customer-provided documents. It organizes requirements by module, records assumptions and open questions, and links requirements to design and acceptance criteria. See [`analysis/README.md`](analysis/README.md) for the source documents, scope notes, and a full index of the analysis files.

# 店内助手（复用 GitHub 组件，做薄）

版本 v6.1 · 2026-09-21

不重写一套对话引擎。Vue 只做输入框和结果卡片；话由 GitHub 上的 AI 助手库生成，经 `dealer-core` 过滤后再给模型。

## 用户看见什么

经销商用户后台有一个 Assistant 页。问一句，得到短说明 + 本店资源入口。例如：「本店有哪些在库 Toyota」「这辆车为什么不能刊登」。

平台管理员没有这一页。只查本店。电话、邮箱、住址不发给模型。

## 怎么走

1. Vue → Gateway → core。core 认 JWT 和 `dealer_id`。
2. core 用普通查询找出最多 5 条本店车辆/客户编号/广告状态。
3. core 经 Gateway 调 ai-service；ai-service 调 GitHub 组件。
4. core 核对模型返回的 ID 必须是刚才那 5 条里的，再生成卡片。乱编的路径丢掉。
5. 不在对话里改车辆、客户或检查结果。

一次问答同步完成，不用队列、不用向量库、不存复杂多轮（最多带最近 3 句本店已过滤文本）。模型挂了就只显示检索列表，并写明「智能说明暂不可用」。
